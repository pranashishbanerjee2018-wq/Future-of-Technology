## 4. MATHEMATICAL FORMULAS & NUMERICAL COMPUTATIONS

All calculations in `QuantumGravity.m` and `matlab_runner.py` employ CODATA recommended physical constants:
- Speed of light: $c = 299792458\text{ m/s}$
- Gravitational constant: $G = 6.67430 \times 10^{-11}\text{ m}^3\text{kg}^{-1}\text{s}^{-2}$
- Reduced Planck constant: $\hbar = 1.054571817 \times 10^{-34}\text{ J}\cdot\text{s}$
- Boltzmann constant: $k_B = 1.380649 \times 10^{-23}\text{ J/K}$

### 1. Fundamental Planck Dimensions
$$l_P = \sqrt{\frac{\hbar G}{c^3}} = 1.616255 \times 10^{-35}\text{ m}$$
$$t_P = \sqrt{\frac{\hbar G}{c^5}} = 5.391247 \times 10^{-44}\text{ s}$$
$$E_P = \sqrt{\frac{\hbar c^5}{G}} = 1.956082 \times 10^9\text{ J} \approx 1.2209 \times 10^{19}\text{ GeV}$$
$$m_P = \sqrt{\frac{\hbar c}{G}} = 2.176434 \times 10^{-8}\text{ kg}$$
$$T_P = \frac{E_P}{k_B} = 1.416784 \times 10^{32}\text{ K}$$
$$\rho_P = \frac{m_P}{l_P^3} = 5.154849 \times 10^{96}\text{ kg/m}^3$$
